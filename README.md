# GoblinBoard — Coordination Practice Project

GoblinBoard is a very small shared task board made only to practise team coordination before the hackathon.

## Goal
Build a working three-column task board using the same general stack planned for the hackathon:

- Next.js + React + TypeScript
- Tailwind CSS
- Supabase + PostgreSQL
- Git + GitHub feature branches
- Vercel deployment if time permits

The project is intentionally small. The real objective is to practise:

- agreeing on contracts before coding;
- splitting work between team members;
- avoiding merge conflicts;
- using small commits and branches;
- integrating frontend and backend work;
- using Codex/AI agents with scoped prompts;
- deploying a working build.

## MVP
- View tasks under Todo / Doing / Done.
- Add a task.
- Set assignee and priority.
- Move/change task status.
- Delete a task.
- Persist data in Supabase.

## Optional only after MVP is stable
- Edit task.
- Filter by member.
- Supabase Realtime.
- Small visual polish / completion effect.

## Important
This is a separate practice repository. Do not copy functional code, components, migrations, or implementation logic from this repo into the official hackathon repo.
